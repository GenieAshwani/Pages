Detailed Curriculum

Module-by-module training roadmap

Each phase builds on the previous. Students leave with depth — not just surface-level familiarity.

Phase 01

Modern Java Foundations

8 Hours

Establish strong Java fundamentals before touching any framework. Students who skip this step often struggle with Spring abstractions — this phase prevents that.

OOP principles — abstraction, inheritance, polymorphism
Collections Framework — List, Map, Set, Queue
Generics, Comparator and clean coding habits
Exception handling and custom exceptions
Functional interfaces, lambdas and method references
Stream API — filter, map, reduce, collect
Optional — safe null handling
Records, sealed classes and modern Java (17–21)
Multithreading basics and ExecutorService
Virtual Threads concept (Java 21)
Java 17–21 OOP Streams Concurrency
Phase 02

HTTP, SQL and Backend Internals

8 Hours

Understanding how backend applications actually work at the HTTP and database layer makes Spring Boot feel like a convenience, not a mystery.

HTTP request-response lifecycle in detail
Servlet architecture, filters, sessions and cookies
SQL — DDL, DML, joins, subqueries, indexing
JDBC — connecting Java to relational databases
Connection pooling concepts
MVC request flow and why it maps to Spring
REST principles — resources, verbs, status codes
JSON structure and request/response design
HTTP MySQL JDBC REST MVC
Phase 03

Spring Boot API Engineering

16 Hours

The core of the program. Students build structured, production-aware REST APIs from scratch — not just hello-world endpoints.

Spring Core — IoC container, DI, bean lifecycle
Spring Boot auto-configuration and project structure
@RestController, @RequestMapping and routing
DTO pattern — request and response separation
Bean Validation — @Valid, @NotNull, custom constraints
Global exception handling with @ControllerAdvice
Spring Data JPA — repositories, query methods, JPQL
Hibernate ORM — entity mapping and relationships
Transaction management with @Transactional
Pagination and sorting with Pageable
MapStruct-style DTO mapping
OpenAPI / Swagger documentation
Spring profiles and environment configuration
Logging with SLF4J and Logback
Spring Actuator for health and metrics
Spring Boot Spring Data JPA Hibernate REST APIs OpenAPI
Phase 04

Spring Security & Authentication

10 Hours

Security is non-negotiable in real APIs. Students implement full authentication and authorization flows from filter chain to method level.

Spring Security 6 architecture — filter chain
Password encoding with BCrypt
JWT — generation, validation, claims extraction
Stateless authentication flow
Role-based access control (RBAC)
Method-level security — @PreAuthorize
OAuth2 login concept and integration basics
CORS configuration for frontend integration
Secure API design patterns
Spring Security 6 JWT OAuth2 RBAC
Phase 05

Generative AI with Spring AI

16 Hours

The distinguishing phase of this program. Students learn how LLMs work conceptually, then integrate them into real Java applications using Spring AI — the fastest-growing addition to the Spring ecosystem.

LLM fundamentals — tokens, temperature, context window
GenAI landscape — GPT-4, Gemini, Llama, Claude
Spring AI framework overview and setup
ChatClient — sending prompts and receiving responses
Prompt engineering — system prompts, few-shot, personas
Streaming responses with SSE (Server-Sent Events)
Structured output — mapping AI responses to Java DTOs
Chat memory and multi-turn conversation management
Tool calling / Function calling concepts
RAG — Retrieval Augmented Generation architecture
Vector embeddings and semantic search concepts
Vector database integration (Chroma / PgVector)
Document ingestion pipeline and chunking strategies
Building a document Q&A system end to end
AI usage analytics and prompt logging
Spring AI RAG LLM APIs Vector DB Prompt Engineering SSE Streaming
Phase 06

Distributed Concepts — Kafka, Redis & Microservices Intro

12 Hours

Exposure to the distributed backend patterns that appear in every senior engineering interview and every scaled product system.

Monolith vs microservices — when and why
Service boundaries and domain decomposition thinking
Apache Kafka — topics, partitions, consumer groups
Producer and consumer patterns in Spring Boot
Event-driven communication between services
Redis — caching, TTL and session storage
Idempotency patterns using Redis
API Gateway and service discovery concepts
Circuit Breaker with Resilience4j basics
Apache Kafka Redis Spring Cloud Microservices Resilience4j

Hands-on Projects

Three production-style projects

Each project reinforces a phase of the curriculum and results in a portfolio item students can present in interviews.

Project 01 — Spring Boot Core

Student Management REST API

A fully layered CRUD REST API with JWT authentication, role-based access, validated DTOs, JPA persistence, OpenAPI documentation and proper error handling — structured across controller, service and repository layers.

Spring Boot Spring Security JWT MySQL OpenAPI
Project 02 — Generative AI

AI Study Assistant with RAG

A Spring Boot-powered AI backend that accepts student questions and answers from a custom knowledge base (PDF notes, documents) using Retrieval Augmented Generation — streaming responses via SSE.

Spring AI RAG Pipeline Vector DB SSE OpenAI API
Project 03 — Distributed System

Event-Driven Notification Service

A multi-service system where a core API publishes events to Kafka, a notification service consumes and processes them, and results are cached in Redis — demonstrating real-world event-driven backend design.

Apache Kafka Redis Spring Cloud Resilience4j Spring Boot

Training Delivery

How the program is structured

📅

Session Format

3 sessions per week, each 2.5 hours long. Each session combines concept explanation, live coding demonstrations and guided exercises.

🛠️

Live Coding Labs

Every phase includes hands-on lab sessions where students build alongside the instructor — not just observe. Code is shared via GitHub repositories.

📊

Assessments

End-of-phase quizzes and practical coding assessments ensure concepts are internalized before progressing to the next module.

🎯

Project Reviews

All three projects go through guided review sessions — students present, explain design decisions and receive structured feedback.

💬

Doubt Resolution

A dedicated support channel (Telegram / WhatsApp group) is maintained throughout the training for real-time question resolution.

🏅

Certification

Students who complete all modules and projects receive a digitally verifiable Certificate of Completion from Code For Success.
